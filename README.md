\# 📊 Meu Aprendizado em MySQL



Bem-vindo(a) ao meu repositório de estudos de banco de dados!



O objetivo deste repositório é documentar meu progresso, desde a criação das primeiras tabelas até consultas e relacionamentos complexos.



\---



\## 📁 Estrutura do Repositório



O projeto está organizado em módulos crescentes de complexidade:



\* \*\*`01-fundamentos-sql/`\*\*: Criação de bancos de dados (`CREATE DATABASE`), tabelas (`CREATE TABLE`) e inserção de dados (`INSERT INTO`).

\* \*\*`02-consultas-e-filtros/`\*\*: Consultas personalizadas usando `SELECT`, filtros com `WHERE`, ordenação com `ORDER BY` e operadores lógicos.

\* \*\*`03-joins-e-agregacoes/`\*\*: Relacionamento entre tabelas (`INNER JOIN`, `LEFT JOIN`) e funções de agrupamento (`GROUP BY`, `COUNT`, `SUM`, `AVG`).

\* \*\*`04-projetos-praticos/`\*\*: Pequenos projetos que simulam cenários reais (ex: e-commerce, sistema de biblioteca, gerenciamento de estoque).



\---



\## 🛠️ Tecnologias e Ferramentas



\* \*\*Banco de Dados:\*\* MySQL Server

\* \*\*Interface Gráfica (SGBD):\*\* MySQL Workbench

\* \*\*Versionamento:\*\* Git e GitHub



\---



\## 🚀 Como Executar os Scripts



Se quiser testar os códigos localmente, você precisará do MySQL instalado na sua máquina:



1\. Instale o \*\*MySQL Server\*\* e o \*\*MySQL Workbench\*\*.

2\. Clone este repositório:

3\. Abra o MySQL Workbench e conecte-se à sua instância local.

4\. Abra qualquer arquivo `.sql` deste repositório no Workbench e execute as queries (`Ctrl + Shift + Enter`).
